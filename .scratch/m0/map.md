- [OAI-PMH client: sickle or hand-rolled?](issues/03-oai-pmh-client.md): hand-rolled httpx + lxml (sickle is unmaintained and can't take our rate limiter); `from` is inclusive at UTC day level; errors come back as HTTP 200; the spec now records first_seen_datestamp instead of announced_date; fixtures are on branch `research/oai-pmh-client`.
- [LaTeX flattening and detex tooling](issues/02-latex-flattening-tooling.md): our own ~100-line stdlib flattener (pandoc, pylatexenc and arxiv_latex_cleaner rejected); pypdfium2 for PDFs; the research recommends raw LaTeX as the canonical text, which the quote format ticket decides.
- [Quote format: raw LaTeX or detexed prose?](issues/01-quote-format.md): quotes are raw flattened LaTeX (PDF → pypdfium2 text), matched through one shared `canonicalise()`; quotes are contiguous 5–60-word spans; Verify derives `loc` from the match instead of checking it; KaTeX renders quotes; a cheap caption-picked `key_figures` field is in M0.
- [Card schema v1 and Read prompt v1](issues/04-card-schema-and-read-prompt-prototype.md): `CardDraft` (model output, quotes before value) plus a stored `Card`; the model marks `inferred`; opinions sit in one `opinion` block; soft list caps; `{{name}}` prompt placeholders; Read stays at `medium` effort. One real call cost $0.098 (27k in, 3k out) and surfaced a per-field number-grounding gap, now a Verify check; the code is on branch `prototype/card-schema-read-prompt`.
- [Code checks in Verify](issues/06-verify-code-checks.md): numbers are parsed tokens (not glued to identifiers) compared by value plus significant figures, with the sign ignored and error bars split. The invented-number check covers every Fact plus the tl;dr; a miss makes the field unsupported and adds a red badge. A number missing from a field's own quotes makes it inferred. All quotes must pass. `canonicalise_mapped()` offsets give an exact `loc`. Status stays `verified`, with failures stored as `invented_numbers` and `warnings`.
- [Review page design](issues/05-review-page-prototype.md): one column in Card order (layout A) with section pills under a fixed top bar, quotes folded under each value, and a verdict bar fixed to the bottom; Flags are entered inline (`f`, `1`–`4`, note, Enter); keyboard shortcuts throughout; hover help everywhere from one shared dictionary; the top bar is the convention for every page; Read prompt v2 expands acronyms and names authors as "X et al."; the code is on branch `prototype/review-page`.
- [Code conventions and runtime plumbing](issues/07-code-conventions.md): all instance state (data plus `config.toml`, `questions.yaml`, `golden/`, `CHANGELOG.md`) lives in `$PHY_HOME` (default `~/.phy-agent-platform`, a local git repo phy never commits to); flat `src/phy/` modules; Typer; raw sqlite3 with `user_version` migrations; Pydantic config with `extra="forbid"`; structlog (readable stderr plus JSONL, SQLite first for metrics); pytest with respx and opt-in `-m live`; credentials via the SDK's own chain with `ant auth login` as default; `flock` locks; Python 3.13 and ruff.
- [How the Golden run-to-run diff is shown](issues/10-golden-diff-display.md): CLI summary plus an `/eval/<id>` page; the baseline is the latest run accepted with `phy eval accept` (which checks config matches and refuses hard fails); the diff is stored on `eval_runs`; only material changes (Support, numbers, failing quotes, list items added or removed, Filter decisions) turn the tile red, while rewordings are folded; lists are paired by content; opinion changes are never red.
- [Filter prompt v1 and its output schema](issues/09-filter-prompt-prototype.md): one call returns `{Qn: {reason, score}}`, with the schema built from the `questions.yaml` ids; the score is a float 0–1 anchored at 0.9/0.7/0.5/0.3/0.1 and clamped in code; reasons run at most 20 words, before the score; the Filter prompt is its own system prompt, and with the schema it makes a cached prefix of about 1,350 tokens (above the 512 minimum); a shared `render_questions()` never shows keywords, and a new `scope_notes` list carries the prose out-of-scope rules; a warm call costs $0.00015 per Candidate; the code is on branch `prototype/filter-prompt`.
- [Monitoring page layout and the SQL behind each tile](issues/11-monitoring-page.md): tile wall grouped by question with a one-line-per-red-tile action list on top; grey tiles for nothing-to-compute; every tile is one SQL query over the §6 tables with no new columns (dates via `run_id` → `runs`, field totals via `json_tree`); 7-day windows except precision (14 d) and spend (ISO week); activity funnel; yes+partly is relevant; two Reader-time tiles (minutes per relevant paper, with a time multiplier as its note, and minutes on "no" Cards); a new `/runs` list page is what tiles link to; the code is on branch `prototype/monitor-page`.
- [Slice M0 into implementation tickets](issues/08-slice-m0.md): 17 ordered test-first build tickets in `.scratch/m0-build/` (smoke path → pipeline → instruments → HITL burn-in); `read --paper` uses OAI `GetRecord`; prototypes are lifted under tests; one migration per slice; unattended runs execute a Release (semver tag) checked out at `$PHY_HOME/app`, with an "update available" badge and `phy schedule update`; the 7-day burn-in starts after slice 11.
- [Anthropic API facts for Read spend control](issues/13-read-spend-api-facts.md): billing and spend-limit errors are 400 `invalid_request_error`, matched by message text only; Console caps are monthly; `count_tokens` is free but fails at zero balance; chars/4 underestimates LaTeX by about 2x; config's Sonnet `cache_read` price is twice the list price; the Read system prompt has no cache breakpoint; findings are on branch `research/read-spend-api-facts`.
- [Restart the burn-in now, on a config-only spend guard?](issues/14-restart-burn-in.md): yes; the budget is $5 a week (quota 3, ceiling 20, `always` at 0.95), set in `$PHY_HOME` with no Release; no deadline for the code fixes; top up $20 and set a $25 monthly Console limit; eval spend counts against the budget but not against the ceiling; day 1 is the first scheduled run after the Reader re-installs that advances the mark.
- [Sign off the calls the slice PRs left for the Reader](issues/19-sign-off-slice-calls.md): the Filter, `/review` and Stale calls are confirmed as built; a fix slice moves per-Paper successes to DEBUG, quiets `launchd.err` and renames the job Label; there's no Card for 1904.12072 yet, so the smoke test runs right after the top-up; the instance is switched to Read prompt v2, and `phy status` will warn on prompt-version drift.
- [Diagnose the max_tokens runaway on 2610.13589](issues/15-max-tokens-runaway.md): a degenerate decoding loop (about 14k of 16k output tokens were `]` inside an open string), not a big Card or an overrunning list; the input was ordinary (38.5k tokens); it's 1 failure in 98 Reads; the next-largest output is 5,039 tokens; the cheapest guard is `max_tokens` of about 8k.
- [Read selection and the guardrail: bounding spend per run](issues/16-read-selection-and-guardrail.md): `always` is first in line but within the quota (no `daily_max`); the quota carry stays; before each call Read estimates the cost (characters / 2 input plus 5k output) and stops the run if it would pass the budget; the ISO week stays the only window; ties go to the higher score sum, then newest; the review backlog stays as is.
- [Per-Card cost: input-token cap, the too_long outcome and paper-text caching](issues/17-per-card-cost.md): no caching in Read (the prefix never repeated); `READ_MAX_TOKENS` is 8k; `read.max_input_tokens` is 150k (characters / 2, checked before the call), with a `skipped` runs row that selection excludes and that `phy status` lists; `--force` skips the cap; the Sonnet `cache_read` price is corrected to 0.10.
- [Read failure bookkeeping, and what --force does to a reviewed Card](issues/18-read-failure-bookkeeping.md): `--force` refuses a Card with a Review or Flags; an insert failure marks the run `failed`; pre-call failures already get a row; Verify drops unknown question ids with a warning; errors that mean the account can't pay abort Read and Filter (an `aborted` run, one ERROR); after 3 failed Reads a Paper is excluded.
- [Keep, wire up or drop the verify.normalize knob](issues/12-verify-normalize-knob.md): drop it; 48 of 1,618 real quotes fail (27 short equations, about 11 formatting, about 10 real misquotes), so `canonicalise` gains six specific rules and the minimum becomes 5 words or 30 characters (amending Quote format); re-verify every Card after the fix Release.
